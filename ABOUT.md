# About React Slop 🎨

In a world increasingly filled with "AI slop," the question arises: how well do AI models actually perform when building software?

## The Experiment
This project was born out of curiosity. We often hear about projects built entirely by AI, but do these models even reach 80% of a complete, functional app? How far do they get without human intervention or a "human guide" telling them how it should actually be done?

With the rise of new models like Claude and Gemini (Flash 3.5), now is the perfect time to explore the boundaries.

## Our Philosophy
For every project in this repository, we apply a simple principle:
**1 target audience, 1 problem, 1 solution.**

## How it was Built
The entire codebase of this open-source project was generated using AI. However, this process was not without its challenges. Significant manual guidance and adjustments were required because AI often cannot figure it out independently.

The result is the product of intensive "background prompting"—while grabbing coffee or before going to bed—followed by testing and correcting the output.

### Automation & Costs
- **GitHub Actions:** New projects added to this repo are automatically deployed via GitHub Actions.
- **Manual Control:** The script to request a new project is run manually to prevent unnecessary (API) costs.

## Proof of Concept
This is a visual proof of turning an idea on paper into a working product. Mind you: it remains "AI slop" until experienced programmers turn it into a real, robust project!

## Discover the Projects
You can find all generated projects here: [https://harm-nullix.github.io/react-slop/](https://harm-nullix.github.io/react-slop/)

Each project is tagged with the AI model used. Some interesting concepts:
1. [**Caffeine Sync**](https://harm-nullix.github.io/react-slop/caffeine-sync/): Calculates the optimal moment for your next cup of coffee.
2. [**Vocalage**](https://harm-nullix.github.io/react-slop/vocalage-voice-biomarker-age-estimator/): Estimates how old your voice sounds.
3. [**Chromaphon**](https://harm-nullix.github.io/react-slop/chromaphon/): An experimental project involving letters and sound.
