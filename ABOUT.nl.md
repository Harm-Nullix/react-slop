# Over React Slop 🎨

In een wereld die zich steeds meer vult met "AI slop", rijst de vraag: hoe goed presteren AI-modellen nu echt bij het bouwen van software?

## Het Experiment
Dit project is ontstaan uit nieuwsgierigheid. We horen vaak over projecten die volledig door AI zijn gebouwd, maar halen deze modellen überhaupt de 80% van een complete, functionele app? Hoe ver komen ze zonder menselijke interventie of een "menselijke gids" die vertelt hoe het eigenlijk echt moet?

Met de opkomst van nieuwe modellen zoals Claude en Gemini (Flash 3.5), is dit het perfecte moment om de grenzen te verkennen.

## Onze Filosofie
Bij elk project in deze repository hanteren we een simpel principe:
**1 doelgroep, 1 probleem, 1 oplossing.**

## Hoe het is gebouwd
De volledige codebase van dit open-source project is gegenereerd met behulp van AI. Dit proces was echter niet zonder uitdagingen. Er is veel handmatige guidance en aanpassing nodig geweest omdat AI er vaak niet zelfstandig uitkomt.

Het resultaat is het product van intensief "prompten" op de achtergrond—tijdens het koffie halen of voor het slapengaan—gevolgd door het testen en corrigeren van de output.

### Automatisering & Kosten
- **GitHub Actions:** Nieuwe projecten die aan deze repo worden toegevoegd, worden automatisch online gezet via GitHub Actions.
- **Handmatige Controle:** Het script om een nieuw project aan te vragen wordt handmatig gedraaid om onnodige (API) kosten te voorkomen.

## Proof-of-Concept
Dit is een visueel bewijs van een idee op papier naar een werkend product. Let wel op: het blijft "AI slop" totdat ervaren programmeurs er een echt, robuust project van maken!

## Ontdek de Projecten
Je kunt alle gegenereerde projecten hier vinden: [https://harm-nullix.github.io/react-slop/](https://harm-nullix.github.io/react-slop/)

Elk project is voorzien van tags en de naam van het gebruikte AI-model. Enkele interessante concepten:
1. [**Caffeine Sync**](https://harm-nullix.github.io/react-slop/caffeine-sync/): Berekent het optimale moment voor je volgende kop koffie.
2. [**Vocalage**](https://harm-nullix.github.io/react-slop/vocalage-voice-biomarker-age-estimator/): Schat in hoe oud je stem klinkt.
3. [**Chromaphon**](https://harm-nullix.github.io/react-slop/chromaphon/): Een experimenteel project met letters en geluid.
